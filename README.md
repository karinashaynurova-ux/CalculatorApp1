CalculatorApp

Калькулятор на Windows Forms (C#)

## Возможности программы

* Сложение
* Вычитание
* Умножение
* Деление
* Очистка результата
* Последовательные вычисления
* Обработка ошибок
* Сохранение результата
* Загрузка результата
* Смена цветовой темы

## Технологии

* C#
* Windows Forms
* .NET Framework
